## ⚡ Quick Start

**5 minutes to our first conversation**

### Step 1: Get Your Keys 🔑

```bash
# You'll need:
✓ LiveKit Cloud (URL + API Key + Secret) → livekit.io
✓ Google Gemini API Key → ai.google.dev  
✓ Gmail App Password (optional) → for email features
```

### Step 2: Setup 🛠️

```bash
# Clone me
git clone https://github.com/thesohamdatta/Mia.git
cd Mia

# Windows
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# Mac/Linux
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Step 3: Configure `.env` 📝

```env
LIVEKIT_URL=your_livekit_url
LIVEKIT_API_KEY=your_api_key
LIVEKIT_API_SECRET=your_api_secret
GOOGLE_API_KEY=your_gemini_key

# Optional
GMAIL_USER=your_email@gmail.com
GMAIL_APP_PASSWORD=your_app_password
```

### Step 4: Let's Talk! 🎤

```bash
# Console mode
python agent.py console

# LiveKit Playground (recommended)
python agent.py dev
```

## 🧩 How I Work

<div align="center">

```
┌─────────────────────────────────────┐
│         You speak 🎤                │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   LiveKit Agents Framework          │
│   (Real-time voice processing)      │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Google Gemini Realtime API        │
│   (I understand context + emotion)  │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│         I respond 💬                │
└─────────────────────────────────────┘
```

**Tech Stack**
- 🎙️ [LiveKit Agents](https://docs.livekit.io/agents/) - Voice infrastructure
- 🤖 [Google Gemini](https://ai.google.dev/gemini-api/docs/realtime) - Multimodal AI
- 🐍 Python 3.8+ - Backend
- 🔍 DuckDuckGo - Web search
- 📧 Gmail API - Email integration
